Зачем АЦП и ЦАП в АСУ

датчик → АЦП → ЦП → ЦАП → ИМ

Цепочка

Датчик даёт аналог, ЦП работает с кодами, ИМ снова нужен аналог — поэтому АЦП и ЦАП обязательны.

ЦАП · идея

цифровой код → напряжение / ток

Вход

На вход — параллельный двоичный код. Клик по D3…D0 меняет код и Uвых в демо.

ЦАП · весовые резисторы

ОУ · сумматор · Rос / R

ОУ

Инвертирующий ОУ суммирует токи весовых ветвей. Uвых = −Uоп·(Rос/R)·Σ (Di/2i). Rос — резистор в цепи обратной связи.

ЦАП · матрица R–2R

пример: D2=1 · на узле I → I/2 + I/2

Ток

Клик по D2 D1 D0. Включённый разряд даёт ток I в свою ветвь 2R. Из‑за деления пополам в Iос доходит: D2 → I/2, D1 → I/4, D0 → I/8. Сумма = Iос.

Параметры ЦАП

N разрядов · 2ᴺ уровней · клик по N

Разрядность

N — разряды. Уровней 2N. Кликните ступеньку или биты — увидите код и Uвых. ▶ ход прогоняет все коды.

АЦП · идея

U / I → выборка → квантование → код

Вход

АЦП играет обратную роль ЦАП: непрерывный сигнал → цифровой код.

Типы АЦП

три класса: параллельные · последовательные · посл.-параллельные

Параллельные

Параллельные (flash) — сравнение сразу со всеми уровнями. Максимально быстрые; дорого по числу компараторов.

АЦП · параллельный

клик по шкале Uвх · Un = Uоп · n / N

Компараторы

ОУ в режиме компараторов. На «+» — Uвх, на «−» — опора Un с резистивной матрицы. Выход 1, если Uвх ≥ Un. Клик по шкале Uвх слева.

АЦП · последовательный счёт

Пуск · счёт · Стоп при X(t)=A

Счётчик

Такты наращивают параллельный код. Кликните уровень A на графике, затем Пуск.

АЦП · последовательное приближение

SAR · бит за битом · t = N·tтакт

Старт

Старший разряд ставят в 1. Сравнивают с Uвх; при необходимости сбрасывают и переходят к следующему биту. За N тактов — готовый код.

Параметры АЦП

статика как у ЦАП · клик по Uвх

Разрядность

N — число двоичных разрядов выходного кода. Кликните по оси Uвх — увидите код. Статика аналогична ЦАП.

Z-преобразование

X(z) — функция комплексного z

X(z) = ∞Σk = 0 xk z−k
= x0 + x1z−1 + x2z−2 + x3z−3 + …

Определение

Отсчёты АЦП — последовательность {xk}.

Z · геометрическая {1, a, a², …}

{xk} = (1, a, a², a³, …)

X(z) = 1 + az−1 + a2z−2 + …

Идея

Все единицы — частный случай: a = 1.

Z · свойства

Линейность

Сумма последовательностей → сумма X(z).

Z · пример

истина 5.0 · авария если > 5.5 · Tд = 1 с

Задача

В трубе давление всегда 5.0. Клапан аварии открыть, только если измерение > 5.5. Датчик шумит. АЦП раз в 1 с даёт число.

Z · что такое H(z)

Три числа

ПЛК помнит три отсчёта.

Z · бесконечная память

Идея

Фильтр помнит всю историю через прошлый выход.

Z · обратное

готовые пары (таблица)

{xk}X(z)
(1, 0, 0, …)1
(1, 1, 1, …)zz − 1
(1, a, a², …)zz − a

прямое и обратное — одна таблица, читаем в обе стороны

Идея

Обратное Z возвращает отсчёты из X(z).

Z · связь с Фурье

  1. 1 · Z

    z — комплексная переменная. Отсчёт xk стоит при степени z−k.

    X(z) = ∞Σk = 0 xk z−k

  2. 2 · Фурье

    Та же сумма. Вместо степени z — экспонента.

    S(iω) = Δ ∞Σk = 0 xk e−iωkΔ

  3. 3 · Степень

    Экспоненту записывают как степень.

    e−iωkΔ = (eiωΔ)−k

  4. 4 · Замена

    Положить z = eiωΔ. Фурье становится суммой Z, умноженной на Δ.

    z = eiωΔ
    S(iω) = Δ ∞Σk = 0 xk z−k
